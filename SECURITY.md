# Security policy

This organization holds the ecashcard.org site. Each card project keeps its own security policy:

- **Cashu Card:** [cashucard/.github SECURITY.md](https://github.com/cashucard/.github/blob/main/SECURITY.md)
- **Fedimint Card:** [fedimintcard/.github SECURITY.md](https://github.com/fedimintcard/.github/blob/main/SECURITY.md)

## Reporting a vulnerability in this organization's repositories

Report it privately: open the affected repository's **Security** tab and choose **Report a vulnerability**, or write to
[hi@ecashcard.org](mailto:hi@ecashcard.org). Please keep vulnerabilities out of public issues and pull requests.

Include as much of this as you can:

- what the vulnerability is and what it puts at risk;
- how to reproduce it;
- a suggested fix, if you have one.

## What to expect

Every report is read, and we keep you informed while we investigate and fix it. Please allow a reasonable window for a
fix before disclosing it publicly.
